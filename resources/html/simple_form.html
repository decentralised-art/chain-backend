Execute

Run a connector on chain, or simulate one you created on this server

Execute runs a connector registered on chain with the chain's runner. Simulate runs a connector you created on this server on its local EVM.

Click any node in the dependency graph (including scalar dots) to edit running instance values.

Only explicitly saved RI values are sent in execute request.

Blue border means static RI is present. "Static RI (locked)" nodes block popup edits; "Fallback RI (overrideable)" nodes can still be edited.

Green glow means dynamic RI is set in popup.

Dotted circles are scalar outputs. Amber boxes with dashed links are connectors introduced by bindings.

Publish

                      
Register one of your entities on chain. Your wallet sends the transaction, or signs it for the server to relay; either way your account pays for it.

                    

                    

                        

                            
Preparation and sending

                            
Prepare builds an unsigned transaction without spending gas. Send with wallet submits it; publication happens when it is successfully mined.

                            
                            

                            
                            

                            
                            
For wallets that can sign a transaction without sending it. The server checks it and broadcasts it through its own node, so the wallet needs no network access; your account still pays. MetaMask cannot sign without sending: leave this off.


                            

                                
                                
                            

                            
A connector's transformations, conditions and composites must be published first.


                            
Confirmation

                            
Confirm checks the transaction receipt to verify that it successfully published this entity for your account. It sends no transaction and spends no gas, so it is safe to repeat. After sending, pending transactions are checked automatically every five seconds for about ten minutes.

                            
                            
                            

                                
                            


                            
Log in, then prepare the publication of an entity you created.

                            
A successful confirmation means the publication was mined. The server's registry listing updates after the block is final, even if you never press Confirm.

                            
After refreshing, select the same entity and Prepare again. If it is already published, its address is shown. To check the original transaction's receipt, paste its hash and press Confirm; do not send it again.
